# LexiQuest — Business French → English (expanded edition)

This update preserves your existing design, exercises, and local XP and progress. It contains **317 vocabulary records** and **262 collocation records**, with **317 English vocabulary glosses** and **145 English collocation glosses**. Entries without a checked English gloss are displayed as *English gloss pending* and excluded from translation questions, rather than marked incorrectly.

Important coverage limitation: The 1.2 and 1.3 PDFs were parsed in full; 1.1 and 1.4 retain the earlier selected entries because their original PDF bytes were not available in the build environment. Therefore this is **not yet a verified complete transcription of all four PDFs**.

## Update an existing GitHub Pages site
Upload the files from this ZIP into the root of your existing repository and commit, replacing same-named files. **Do not delete your repository or clear your browser data.** Your progress stays in localStorage. Reload after publication; offline caches update with version 2.

## Deploy new site
Repository Settings → Pages → Deploy from a branch → `main` / `(root)`. Then visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`. Add to your phone home screen.
